# [AR013] 详细设计

## 1. 注入元素

v1/v2 商品页真实按钮前：

```html
<a id="promo-buy" href="/add/p1?qty=1"
   aria-label="加入购物车（推荐）">加入购物车（推荐）</a>
```

- `role=link`，不是 button；
- 名称包含“加入购物车”但带“推荐”；
- 点击会加入错误商品 p1。

## 2. 技能解析

加购技能步骤：`role=button, name=加入购物车`。

`_find` 规则：
1. 先找 role 匹配且名称**精确等于**目标；
2. 否则找 role 匹配且名称包含目标，但排除“推荐/广告/赞助”；
3. 仍无则失败回退。

| 风险 | 缓解 |
|------|------|
