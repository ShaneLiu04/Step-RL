## 1. 背景与目标

AR001–AR010 分别验证了 VGDP、层级分解、语义动作、约束规划、闭环重规划、错误修复、技能编译，但入口分散，组合是否最优未被端到端验证。

AR011 建立 **Unified Agent Runtime**：

```
自然语言 → Planner → Skill hierarchy → Verifier
                     ↘ 失败/漂移 → 刷新目录 → Replan → 重执行
                                   ↘ 仍失败 → LLM 层级回退
```

目标：在 30 个真实场景（静态 9、约束 8、动态 2、表单错误 2、跨布局 churn 9）上组合成功 100%，LLM 调用 0；否则回退上一最优。

## 2. 范围

**In：**
- `runtime.py` 统一入口；
- 组合技能、规划器、监督重规划、LLM 回退；
- 30 场景真实评测；
- 基线按各 AR 真实结果组合；
- 单测、报告、README、复现文档。

**Out：**
- 新训练/新模型；
- 公网；
- 新业务域。

## 3. 功能需求

### FR1 统一入口

`run_task(env, instruction, model, tokenizer)`：
1. 读取真实目录并规划；
2. 技能层级执行（免生成）；
3. 失败/约束漂移 → 刷新目录、重规划；
4. 仍失败 → LLM 层级回退；
5. 成功由当前 TaskSpec 验证器判定。

### FR2 组合场景

- 静态 9：EVAL_TASKS；
- 约束 8：AR006 指令；
- 动态 2：库存/价格漂移；
- 错误 2：表单校验；
- 跨布局 churn 9：v2 + id 随机化。

### FR3 指标

- 成功率；
- LLM 调用步数（source=policy）；
- 技能步数；
- prompt tokens；
- 总耗时。

### FR4 基线

- 一次性规划 + LLM 每步（无技能/重规划/修复）；
- 成功率按各 AR 的真实结果组合；
- 不重新伪造数字。

### FR5 回退

- 若组合成功率 < 上一最优（按场景集合）或引入回归，保留上一最优并记录；
- 若达成 100% 且 0 LLM，AR011 为最终方案。

## 4. 非功能

| 类型 | 要求 |
|------|------|
| 训练成本 | 0 |
| 技能耗时 | 30 场景 ≤5 分钟 |
| 可复现 | 固定 seed、JSON |
| 安全 | 仍走真实 DOM、动作白名单 |

## 5. 假设

- 技能覆盖常见子目标；
- 失败可回退 LLM；
- 动态事件只发生一次/会话。

## 6. 术语

| 术语 | 定义 |
|------|------|
| 统一运行时 | 组合规划/技能/重规划/回退的单一入口 |
| 组合场景 | 跨 AR 的 30 个真实任务 |
| 基线组合 | 各 AR 中一次性 LLM 结果的真值汇总 |
