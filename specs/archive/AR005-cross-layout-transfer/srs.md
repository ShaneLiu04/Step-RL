## 1. 背景与目标

AR004 证明语义动作能抵抗同一页面的 id 变化，但尚未证明它能迁移到**不同页面结构/组件实现**。真实网站改版通常同时改变 DOM 层级、标签、元素顺序与交互控件。

本 AR 新增第二套真实商城布局 `ShopLite`：

- 不同 id、标签层级、元素顺序；
- 额外干扰按钮（排序/筛选/收藏/返回/继续购物）；
- 业务语义与可访问名保持一致（搜索商品/搜索/加入购物车/去结算/提交订单/收货人/地址）。

在不重新训练的前提下，用 AR004 语义适配器零样本评测；正式压力条件为：

> 未见布局 + 观测快照后随机化全部 DOM id（模拟 SPA 重渲染）

目标：语义策略 100%，selector 策略在该条件下失效；若不达标则回退 AR004。

## 2. 需求范围

**In Scope：**

- `LocalShopServer(layout="v2")` 第二套真实 HTML；
- 语义/selector 两接口在 v2 的稳定与 churn 评测；
- 跨布局零样本结果与回退记录；
- 单测（v2 路由、语义名、真实浏览器执行）；
- README/封面/复现文档。

**Out of Scope：**

- 新任务/新商品/新业务；
- 重新训练跨布局适配器；
- 公网站点。

## 3. 功能需求

### FR1 第二套布局

**描述：** 同一服务端状态与路由，渲染不同 HTML。

**验收：**
- `/`、`/search`、`/product/*`、`/cart`、`/checkout`、`/place-order`、`/order/*` 全部可用；
- v2 不含 `#q/#search-btn/#add-to-cart` 等旧 id；
- 关键控件具备稳定 `aria-label`。

### FR2 语义零样本

**描述：** AR004 语义适配器不重新训练，直接在 v2 执行。

**验收：**
- L1–L2 成功率 100%；
- 9 任务成功率 100%（子目标预算 12）。

### FR3 正式压力条件

**描述：** v2 + 观测后 id 全随机化。

**验收：**
- 语义策略成功率 100%，非法动作 0；
- selector 策略成功率显著低于语义（目标 0%）；
- 两接口使用相同任务、预算、评测协议。

### FR4 公平性

**描述：** selector 与语义使用相同子目标预算与层级控制器。

**验收：**
- 两者都使用 AR003 层级分解与相同适配器训练数据来源；
- 预算同为 12；
- 结果 JSON 记录接口类型与条件。

### FR5 回退

**描述：** 若语义在 v2+churn 低于 AR004 的 100%，回退 AR004。

**验收：**
- 回退时保留 AR004 并记录负结果；
- 若达标，AR005 成为最终方案。

## 4. 非功能需求

| 类型 | 要求 |
|------|------|
| 训练成本 | 0 新增训练 |
| 评测时间 | 单条件 ≤15 分钟（本机限频） |
| 可复现 | 固定 seed、greedy、JSON 产物 |
| 安全 | 语义动作仍经 eid 唯一性与动作白名单 |

## 5. 约束与假设

- v2 与 v1 共享同一业务语义与可访问名；
- 干扰按钮是真实页面元素，不是文案陷阱；
- 语义编号只在当前观测内有效。

## 6. 术语

| 术语 | 定义 |
|------|------|
| 跨布局迁移 | 在未见 HTML 结构上零样本执行 |
| v2 / ShopLite | 第二套真实商城布局 |
| churn | 观测后随机化 id |
| 子目标预算 | 每个子任务最大步数 |
