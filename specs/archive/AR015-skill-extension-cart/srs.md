## 1. 背景与目标

现有技能覆盖搜索/加购/结算，但用户常需要修改购物车数量。当前能力清单会标记未覆盖，需回退 LLM；本轮通过真实演示扩展技能库，验证“可扩展技能”架构。

AR015 增加：

- 真实购物车数量修改页面与路由；
- 精确购物车数量谓词；
- 从真实演示动作扩展 `update_quantity` 技能；
- LLM 基线 vs 扩展技能评测。

目标：扩展技能 3/3；若 LLM 基线也成功，则记录效率收益，不强行制造差距。

## 2. 范围

**In：**
- `/update/<pid>` 路由、购物车数量输入/更新按钮；
- `seed_cart` 初始购物车；
- `cart_quantity_exact` 谓词；
- 规划器识别“改为 N”；
- `update_quantity` 技能；
- 3 个任务评测；单测、报告、README、复现。

**Out：**
- 任意购物车操作；
- 新模型训练；
- 公网。

## 3. 功能需求

### FR1 购物车更新

- 每个购物车项有数量输入与“更新数量 {商品名}”按钮；
- `/update/<pid>?qty=n` 真实更新服务端购物车。

### FR2 初始购物车

- TaskSpec `seed_cart`；reset 后写入真实服务端购物车。

### FR3 精确谓词

- `cart_quantity_exact`：购物车数量必须等于目标。

### FR4 技能

- `update_quantity(pid, qty)`：goto /cart → 找到该商品数量输入 → 输入 → 点击更新；
- 元素按 role + 商品名解析。

### FR5 评测

| 任务 | 初始 | 目标 |
|------|------|------|
| p3 1→3 | p3=1 | p3=3 |
| p4 2→4 | p4=2 | p4=4 |
| p3 3→1 | p3=3 | p3=1 |

- 基线 LLM 层级 vs 扩展技能；
- 成功按精确谓词判定。

## 4. 非功能

| 类型 | 要求 |
|------|------|
| 训练成本 | 0 |
| 技能耗时 | <3s/任务 |
| 可复现 | 固定 seed、JSON |
| 安全 | 真实 DOM/动作白名单 |

## 5. 假设

- 服务端会话可 seed；
- 购物车页可真实修改数量；
- LLM 可能无法稳定完成更新。
