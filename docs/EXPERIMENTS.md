## 2. 实验矩阵

### E1 动作接口 × DOM 扰动概率

**假设**：selector 的成功率随扰动概率单调下降；语义接口保持稳定。

- 接口：selector+repair、semantic
- 扰动概率：0、0.25、0.5、0.75、1.0（每次观测后按概率随机化全部 id）
- 任务：L1–L2 留出 4 个（p3/p4）
- 指标：成功率、非法动作数、修复数、平均步数
- 产物：`outputs/ex001/e1_perturb.json`、曲线图

### E2 层级分解 vs 扁平执行

**假设**：同一语义适配器下，扁平路由在 L4/L5 显著低于层级分解。

- 条件：semantic flat-router vs semantic hierarchy
- 任务：9 个留出任务
- 指标：成功率、按等级成功率、平均步数
- 产物：`e2_flat.json` + 对比图

### E3 验证器感知观测消融

**假设**：移除 `Φ + missing` 提示后，L4/L5 的结算/多商品步骤显著退化。

- 条件：hints on / hints off（同一语义适配器，推理期移除观测字段）
- 任务：9 个留出任务
- 指标：成功率、按等级、缺失谓词
- 产物：`e3_hints.json`

### E4 跨布局 × 重渲染

**假设**：v1 训练 → v2 稳定可靠；v2+churn 下 selector 失效、语义保持。

- 条件：semantic v1、semantic v2、selector v2、semantic v2+churn、selector v2+churn
- 任务：9 个留出任务
- 指标：成功率、非法动作、修复
- 产物：已有 `outputs/ar005` + 汇总表

### E5 约束规划归因

**假设**：关键词基线在规划准确率与期望成功率上显著低。

- 条件：naive baseline、constraint planner、planner+v2+churn
- 指令：8 条（预算/最值/数量/多商品/替代）
- 指标：规划准确率、按用户期望成功率
- 产物：已有 `outputs/ar006` + 逐条审计

### E6 失败分类学

**假设**：不同 AR 的失败集中在不同阶段（搜索/商品/购物车/结算/订单）。

- 数据：AR001–AR006 的所有真实结果 JSON
- 分类：按最终缺失谓词、动作序列、非法/修复、步数耗尽
- 产物：`e6_failures.json`、堆叠柱状图

### E7 稳定性与成本

**假设**：greedy 评测在重复运行间稳定；成功任务的步数/token 成本可量化。

- 条件：3 个代表任务（L3/L4/L5）× 3 次重复
- 指标：成功率方差、平均步数、prompt/gen token、每成功 token
- 产物：`e7_stability.json`

### E8 硬件剖析（CPU + GPU）

**假设**：端侧 0.6B 在受限 GPU 上仍可完成动作生成；CPU 适合规划/验证/服务。

- CPU：planner 延迟、verifier 延迟、HTTP 商城吞吐
- GPU：动作生成延迟、峰值显存、单步 token/s
- 指标：P50/P95 延迟、显存、吞吐
- 产物：`e8_hardware.json`

## 3. 场景化解读框架

| 场景 | 关键设计 | 观察点 |
|------|----------|--------|
| 搜索/加购（L1–L2） | 语义观测 + SFT | selector 与语义是否同分；扰动后差异 |
| 数量控制（L3） | VGDP + Step-GRPO | 稀疏 vs 稠密的训练/留出差异 |
| 结算（L4） | 验证器观测 + 层级分解 | hints 移除后的退化 |
| 多商品（L5） | 层级分解 | 扁平执行的失败位置 |
| 缺货替代 | 约束规划 + 库存 | 规划准确率与执行分离 |
| 页面改版 | 语义接口 + churn | 非法动作/修复变化 |

## 4. 指标定义

- **成功率**：原任务验证器所有谓词满足。
- **按用户期望成功率**：使用期望 TaskSpec，而不是 planner 自身规划（仅 E5）。
- **非法动作率**：选择器/元素在执行时不存在，或动作被白名单拒绝。
- **修复率**：selector 模式下触发 DOM 唯一匹配修复的 episode 比例。
- **步数**：真实浏览器动作数（含控制器导航）。
- **token 成本**：prompt token + generated token；每成功任务 token。
- **稳定性**：重复运行成功率标准差。

## 5. 威胁与边界

1. 本机 GPU 被锁定在 645 MHz，绝对延迟不代表服务器；报告相对差异。
2. 本地商城是自建真实站点，不外推到所有公网网站。
3. E3 为推理期移除观测字段，存在分布偏移；结论限定为“该字段的推理贡献”。
4. E1 的扰动是“观测后 id 随机化”，模拟 SPA 重渲染，不是所有 DOM 变化。
5. 所有结果保留负结果，不选择性报告。
